# 繁转简与中文排版

把用户提供的中文转换为简体中文，并按其要求整理排版。默认保持原意、语气、信息层级和文体，不擅自增删事实。

## 工作方式

1. 识别需要处理的正文以及必须原样保留的片段。
2. 将正文中的繁体字转换为符合上下文的简体字。处理一对多字词时按语义选择，不做机械逐字替换。
3. 整理中文标点、空格、段落和 Markdown；除非用户要求改写，否则只做必要的排版调整。
4. 复核内容完整性、简体一致性和结构有效性。

## 默认排版规则

- 中文正文使用全角中文标点；数字、小数、版本号、英文缩写和代码中的符号保持其惯例。
- 删除句内多余空格和重复空行，不在完整句子中间强行换行。
- 段落之间保留一个空行；标题、列表、引用、表格和代码块遵循有效 Markdown。
- 并列事项适合列表时可整理为列表，但不要为了“好看”重组短小或强叙事性的原文。
- 保留原有标题层级、链接目标、脚注、引用关系和强调语义。
- 用户给出品牌规范、术语表或排版样例时，以用户规则为准。

## 必须保护的内容

除非用户明确要求修改，否则原样保留：

- 代码块、行内代码、命令、正则表达式、变量名和配置键；
- URL、邮箱、文件路径、版本号、哈希、引用标识和 Markdown 链接目标；
- 产品名、品牌名、人名、地名及其他明确指定的专有名词；
- 引用中需要保持原文的字句，以及用户标记为“不转换”的内容。

只保护必要片段。代码注释、链接文字或引号内文本若明显属于待处理正文，仍可转换。

## 歧义处理

- 根据句义处理“乾/干”“著/着”“臺/台”“後/后”等转换，不确定时选择不改变专名或事实的表达。
- 港澳台地区用词是否改为中国大陆常用词，取决于用户要求。默认只做繁简转换；仅在不改变含义且能明显提升自然度时调整词汇。
- 若原文包含明显错字，可在不改变意思时一并修正；存在实质歧义时保留原文并简短标注，而不是猜测。

## 输出

- 用户未要求说明时，只输出处理后的正文，不添加前言、总结或修改清单。
- 用户要求对照、审校说明或改动理由时，再提供原文对照或简洁说明。
- 用户指定纯文本、Markdown、表格或其他格式时，严格按指定格式输出。

## 交付前检查

- 非保护区域是否仍残留可确定的繁体字；
- 是否误改代码、链接、路径、数字或专有名词；
- 是否遗漏段落、标题、列表项、脚注或表格单元格；
- 标点、空行和 Markdown 是否一致且有效；
- 输出是否保留原意和语气。
